## Why this return

- Still finishes on Day 21 without grind days.
- Prairie line shifts north/south of the outbound ladder (Yorkton / Moose Jaw / Brooks vs Regina / Brandon / Medicine Hat).
- Mountains home via **Revelstoke → Hope** instead of Golden → Kamloops.
- Short Day 18 (Brooks → Calgary) and Day 21 (Hope → ferry) keep the end of the trip easy.

---

## Essentials

1. **BC Ferries:** Reserve outbound and **Day 21** return (Hope is close — an afternoon sailing works).
2. **Verify before dark** on every new return lot — policies change.
3. **Water / dump** at prairie Flying J / Co-op stops on return days.
